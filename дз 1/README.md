# Домашнее задание № 1 — Калькуляторы и функции

[← К описанию репозитория](../README.md)

## Цель
Освоить ввод данных, условные операторы, функции, циклы, классы и обработку исключений на примере калькулятора.

## Состав работы
| Файл | Назначение |
|---|---|
| `number1.1.py` | Простейший калькулятор: ввод двух целых чисел и символа операции, ветвление `if/elif/else`. |
| `number1.2.py` | Вынесение сложения, вычитания, умножения и деления в отдельные функции. |
| `number1.3.py` | Единая функция `f(a, b, s)` и многократное выполнение операций в бесконечном цикле. |
| `number1.4.py` | Расширенный консольный инженерный калькулятор с меню, классами, историей и памятью. |

## Реализованная функциональность
Первые три версии выполняют `+`, `-`, `*`, `/`. Для деления на ноль предусмотрен вывод `ERROR`. В этих версиях любой символ, кроме `+`, `-` и `*`, приводит к попытке деления — это особенность реализации, а не проверка корректности оператора.

В `number1.4.py` применяются базовый класс `Calculator`, наследующий его `EngineeringCalculator` и консольный интерфейс `CalculatorCLI`. Реализованы арифметические и инженерные операции, история вычислений, хранение значения в памяти и обработка ошибок. Используется стандартный модуль `math`.

## Запуск
Из каталога задания:
```bash
python number1.1.py
python number1.2.py
python number1.3.py
python number1.4.py
```
Для `number1.1.py`–`number1.3.py` вводите два целых числа (каждое с новой строки), затем оператор. `number1.3.py` повторяет запросы бесконечно: остановка через `Ctrl+C`. В `number1.4.py` следуйте текстовому меню, `0` — выход.

## Пример для простых версий
```text
8
2
*
16
```

## Зависимости
Только стандартная библиотека Python. Рекомендуется Python 3.10+.

## Результат
Переход от линейной программы к декомпозиции на функции и объектно-ориентированной модели калькулятора.
