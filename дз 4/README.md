# Домашнее задание № 4 — Анализ Titanic с Pandas и NumPy

[← К описанию репозитория](../README.md)

## Цель
Выполнить загрузку, очистку, исследовательский анализ и статистическую обработку реального табличного набора данных о пассажирах «Титаника».

## Исходные данные
`train.csv`: 891 строка и 12 столбцов. В числе признаков — `Survived`, `Pclass`, `Sex`, `Age`, `Fare`, `Embarked`, `Cabin`.

## Этапы работы
1. Загрузка CSV в `DataFrame`, знакомство с `Series`, `head`, `tail`, типами данных и описательной статистикой.
2. Анализ пропусков. В `Cabin` отсутствуют 687 значений, в `Age` — 177, в `Embarked` — 2.
3. Заполнение `Age` медианой 28, удаление двух записей с пропущенным `Embarked`, удаление `Cabin` из-за большого количества пропусков. Итоговая таблица: 889 × 11.
4. Вычисления с NumPy: средние значения, стандартные отклонения, доли выживших.
5. Булева фильтрация пассажиров по нескольким условиям; экспорт четырёх выборок.
6. Группировка по классу, полу и порту посадки; вычисление агрегированных показателей.
7. Сохранение результатов и проверка повторной загрузки CSV.

## Результаты анализа
По приложенному отчёту: общая выживаемость — **38,38 %**, среди женщин — **74,20 %**, среди мужчин — **18,89 %**. Наибольшая доля выживших — в первом классе (**62,62 %**). Это показатели исходной выборки, а не вывод о причинности.

## Установка и запуск
Из папки задания:
```bash
python -m pip install pandas numpy
python titanic_analysis.py
```
На запрос количества строк можно нажать Enter (по умолчанию 5). Программа читает `train.csv` рядом со скриптом и записывает результаты в ту же папку, перезаписывая одноимённые выходные CSV.
