# Домашнее задание № 6 — Калькулятор с SQLite

[← К описанию репозитория](../README.md)

## Цель
Расширить графический калькулятор локальной реляционной базой данных SQLite для постоянного хранения истории вычислений.

## Файлы
| Файл | Стек | Назначение |
|---|---|---|
| `calculator_tkinter_sql.py` | Tkinter, SQLite | Калькулятор с историей в локальной БД. |
| `calculator_pyqt5_sql.py` | **PyQt5**, SQLite | Калькулятор на Qt с таблицей истории и вкладками. |
| `calculator.db` | SQLite | Создаётся приложением при первом запуске, в архиве отсутствует. |

## Возможности
- Пять операций: `+`, `−`, `×`, `÷`, `^`.
- Проверка числового ввода и обработка ошибочных вычислений.
- Сохранение вычислений в таблице `calculations` с автоматически назначаемым идентификатором и датой/временем.
- Просмотр и удаление записей истории через графический интерфейс.
- Сохранение истории между запусками за счёт файла SQLite.

## База данных
Обе версии используют таблицу `calculations`, но **схемы различаются**:
- Tkinter: `id`, `first_number`, `second_number`, `operation`, `result`, `created_at`.
- PyQt5: `id`, `first_number`, `second_number`, `operation_index`, `operation_symbol`, `result`, `created_at`.

**Важно:** оба скрипта создают `calculator.db` в одной папке. Их схемы не полностью совместимы. Для независимой проверки запускайте версии по отдельности, предварительно переименовав или сохранив резервную копию существующей БД; не используйте одну базу одновременно для обеих версий. PyQt5-реализация содержит процедуру миграции некоторых старых схем, но не гарантирует совместимость с таблицей Tkinter.

## Запуск
Вариант Tkinter:
```bash
python calculator_tkinter_sql.py
```
Вариант PyQt5:
```bash
python -m pip install PyQt5
python calculator_pyqt5_sql.py
```

## Зависимости
`sqlite3` и `tkinter` — стандартная библиотека Python (Tkinter может требовать системный пакет). Для Qt-варианта нужна **PyQt5**, не PyQt6.

## Результат
Графическое приложение с постоянным хранением вычислений, SQL-запросами и обработкой пользовательских операций.
