# Домашние задания по Python

**Учебный репозиторий — 6 домашних заданий по программированию на Python.**

В репозитории собраны исходные программы, необходимые данные, результаты выполнения и документация. Задания охватывают базовый синтаксис Python, функции и классы, обработку строк, работу со списками, анализ табличных данных, разработку графических интерфейсов и использование базы данных SQLite.

> **Для проверяющего:** каждое домашнее задание находится в отдельной папке `дз N/`. В ней размещены исходные файлы и собственный `README.md` с описанием реализации и инструкцией по запуску. Основные файлы и команды запуска перечислены ниже.

## 2. Что проверять в каждом задании

### Домашнее задание № 1 — Калькуляторы

**Файлы:** `number1.1.py`, `number1.2.py`, `number1.3.py`, `number1.4.py`.

Последовательное усложнение консольного калькулятора: от условий и простых арифметических действий к функциям, повторным вычислениям и объектно-ориентированной реализации. В `number1.4.py` представлены дополнительные возможности инженерного калькулятора, включая память и историю.

**Проверка:** открыть любую программу и выполнить предлагаемые операции с числами. Для наиболее полной версии запустить:

```bash
python "дз 1/number1.4.py"
```

### Домашнее задание № 2 — Строки

**Файлы:** `lv1.py` — `lv5.py`.

Практика стандартных методов `str`: изменение регистра, поиск и замена, проверка содержимого, удаление пробелов, `split()` и `join()`. Итоговая программа `lv5.py` объединяет строковые операции в интерактивном меню.

**Проверка:**

```bash
python "дз 2/lv5.py"
```

### Домашнее задание № 3 — Лабиринт

**Файл:** `labyrinth_game.py`.

Консольная игра, построенная на двумерных списках. Реализованы перемещение по карте, разные типы комнат, случайные события, взаимодействие с предметами и хранение игрового состояния. Задание демонстрирует работу со списками на примере законченного игрового сценария.

**Проверка:**

```bash
python "дз 3/labyrinth_game.py"
```

Управление и условия прохождения описаны в [README задания № 3](дз%203/README.md).

### Домашнее задание № 4 — Анализ Titanic

**Основные файлы:** `titanic_analysis.py`, `train.csv`, `execution_results.txt`, `titanic_processed.csv`, `titanic_statistics.csv` и дополнительные CSV с результатами фильтрации и анализа.

Используются **Pandas и NumPy**. Выполнены исследование структуры данных, анализ пропусков, заполнение отсутствующего возраста медианой, фильтрация, группировка, расчёт статистических показателей и сохранение обработанных таблиц.

Исходный набор содержит **891 строку и 12 столбцов**. После обработки — **889 строк и 11 столбцов**. Общая доля выживших в исходных данных составляет **38,38 %**.

**Проверка:**

```bash
python "дз 4/titanic_analysis.py"
```

Результаты можно проверить без запуска программы в `execution_results.txt` и выходных CSV. При повторном запуске программа может перезаписать выходные файлы.

### Домашнее задание № 5 — GUI-калькуляторы

**Файлы:** `calculator_tkinter.py`, `calculator_pyqt5.py`.

Две самостоятельные оконные реализации калькулятора с вводом значений, выполнением математических операций и обработкой некорректного ввода.

**Проверка (достаточно запустить одну из версий, для сравнения — обе):**

```bash
python "дз 5/calculator_tkinter.py"
python "дз 5/calculator_pyqt5.py"
```

**Важно:** несмотря на имя `calculator_pyqt5.py`, этот файл использует библиотеку **PyQt6**, а не PyQt5.

### Домашнее задание № 6 — GUI-калькуляторы с SQLite

**Файлы:** `calculator_tkinter_sql.py`, `calculator_pyqt5_sql.py`.

Развитие предыдущего задания: оконные калькуляторы сохраняют историю вычислений в локальную базу данных **SQLite**. Реализованы SQL-операции создания таблицы, добавления записей и получения истории.

**Проверка:** запустить выбранную реализацию, выполнить несколько вычислений и проверить сохранение/просмотр истории.

```bash
python "дз 6/calculator_tkinter_sql.py"
# или
python "дз 6/calculator_pyqt5_sql.py"
```

**Важно:** в ДЗ № 6 версия на PyQt использует **PyQt5**. Две версии программы создают базу с одинаковым именем `calculator.db`, но с различающимися схемами таблиц. Для независимой проверки запускайте их с отдельными файлами БД (например, в разных рабочих каталогах), не используя одну базу для обеих реализаций.

## 3. Подготовка окружения

**Требования:** Python 3.10+ (рекомендуется), графическая среда для ДЗ № 5–6. Для ДЗ № 1–3 внешние библиотеки не требуются. SQLite входит в стандартную библиотеку Python.

Из корня репозитория:

```bash
python -m venv .venv
```

Активировать окружение:

```bash
# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS / Linux
source .venv/bin/activate
```

Установить зависимости:

```bash
python -m pip install -r requirements.txt
```

Файл `requirements.txt` содержит `numpy`, `pandas`, `PyQt5` и `PyQt6`. Tkinter обычно поставляется с Python, но на некоторых системах Linux устанавливается отдельно.

> Команды запуска выше рассчитаны на выполнение **из корня репозитория**. Если программа использует относительные пути к данным, удобнее сначала перейти в папку соответствующего задания и запускать её оттуда. В частности, для анализа Titanic используйте `cd "дз 4"` и затем `python titanic_analysis.py`.
