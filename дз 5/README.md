# Домашнее задание № 5 — Графический калькулятор

[← К описанию репозитория](../README.md)

## Цель
Реализовать настольный калькулятор с графическим интерфейсом в двух GUI-фреймворках и сравнить подходы к построению оконных приложений.

## Реализации
| Файл | Технология | Описание |
|---|---|---|
| `calculator_tkinter.py` | Tkinter / ttk | GUI на стандартной библиотеке Python. |
| `calculator_pyqt5.py` | **PyQt6** | GUI на Qt; имя файла историческое и не соответствует фактической библиотеке импорта. |

Оба приложения предлагают ввод двух чисел, выбор операции, отображение результата и обработку ошибок. Поддерживаются сложение, вычитание, умножение, деление и возведение в степень. Реализованы очистка полей и окно с информацией о программе.

## Запуск
Из каталога задания:
```bash
python calculator_tkinter.py
```
Для второго варианта установите **PyQt6**:
```bash
python -m pip install PyQt6
python calculator_pyqt5.py
```

## Зависимости
- Tkinter / ttk — обычно поставляются с Python; в отдельных Linux-дистрибутивах пакет `python3-tk` устанавливается отдельно.
- PyQt6 — внешняя библиотека, необходимая только второму варианту.

## Результат
Две независимые реализации оконного калькулятора. В этой работе база данных ещё не используется; сохранение истории добавлено в задании № 6.
