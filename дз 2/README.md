# Домашнее задание № 2 — Методы строк Python

[← К описанию репозитория](../README.md)

## Цель
Освоить основные методы строк и построить единый интерфейс их вызова по команде пользователя.

## Файлы и методы
| Файл | Методы / назначение |
|---|---|
| `lv1.py` | `upper`, `lower`, `capitalize` — изменение регистра. |
| `lv2.py` | `find`, `replace`, `count` — поиск, замена и подсчёт вхождений. |
| `lv3.py` | `split`, `split join`, `join` — разделение и соединение текста. |
| `lv4.py` | `isdigit`, `isalpha`, `strip`, `lstrip`, `rstrip`, `format` — проверка и обработка строк. |
| `lv5.py` | Объединение функций `lv1`–`lv4` и последовательное применение выбранных методов в цикле. |

## Особенности реализации
- В `lv2.py` поиск и подсчёт выполняются для фиксированного слова `круто`; замена — `круто` → `тупо`.
- В `lv3.py` команда `split join` удаляет запятые, а в `lv5.py` — пробельные разделители: реализации отличаются.
- `join` вызывается для строки, поэтому соединение её символов без разделителя не меняет текст.
- `format` вызывается без аргументов: шаблоны с незаполненными полями могут вызвать исключение.
- `lv4.py` определяет функцию, но не выводит её результат: после ввода двух строк программа завершается. Для просмотра результата удобнее `lv5.py`.
- В `lv5.py` результат каждой операции становится входной строкой для следующей. Методы `find`, `count`, `isdigit`, `isalpha` возвращают число или `bool`, поэтому последующие строковые методы могут вызвать ошибку типа.

## Запуск
```bash
python lv1.py
python lv2.py
python lv3.py
python lv4.py
python lv5.py
```

