# Домашнее задание № 3 — Консольная игра «Лабиринт»

[← К описанию репозитория](../README.md)

## Цель
Создать интерактивную игру на основе двумерного списка и продемонстрировать работу со списками, словарями, классами и случайной генерацией.

## Основной файл
`labyrinth_game.py` — самостоятельная консольная игра. При запуске пользователь выбирает размеры поля: от 3 до 10 строк и столбцов.

## Игровые механики
- Лабиринт представлен сеткой комнат, по которой перемещается игрок.
- В комнатах могут находиться сундуки, монстры, ловушки, ключи, порталы и выход.
- Игрок взаимодействует с предметами, управляет инвентарём, сражается с противниками и ищет путь к выходу.
- Состояние комнат хранится в объектах `Room`, а логика игры — в `LabyrinthGame`.
- Применяются случайная генерация и учёт уже посещённых или изменённых комнат.

## Методы списков
В исходном коде демонстрируются `append`, `extend`, `remove`, `pop`, `sort`, `reverse`, оператор `in`, `index`, `copy`, срезы, `deepcopy` и списковые включения (`list comprehension`). `deepcopy` нужен для независимого копирования вложенных объектов.

## Запуск
```bash
python labyrinth_game.py
```
После запуска задайте размеры поля и следуйте командам, которые выводит игровое меню. Направления перемещения обозначаются `w`, `a`, `s`, `d`.

## Зависимости
Только стандартная библиотека Python (`random`, `copy`, `dataclasses`, `typing`). Рекомендуется Python 3.10+.

## Результат
Полноценный учебный консольный проект, объединяющий работу со списками, управление состоянием игры и объектно-ориентированный подход.
